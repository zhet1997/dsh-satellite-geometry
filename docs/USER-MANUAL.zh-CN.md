# 卫星几何工作台 · 用户简明手册

适用版本：0.3.1。面向已经在服务器上安装并开通插件的热设计工程师。

本工作台将整星 STEP 和配套资料整理为简化几何、单机建模方案及热接触清单。基本流程是：**导入 → 一键建模 → 工程师修正 → 检查 → 导出**。网格划分和热分析求解由下游工具完成。

## 1. 进入工作台

打开管理员提供的 DSH 网页，进入 **卫星几何工作台**，在左侧创建或选择对话会话，确认模型可用。右上角应显示 **计算服务已连接**。

如尚未连接，在 **设置 → 内置插件 → 卫星几何** 中填写管理员提供的几何服务地址；需要时填写访问令牌，再检查连接。已经连接的用户可直接开始使用。

页面左侧是 DSH 对话；右侧工作台内依次为工程目录、三维视图和单机详情。**几何工程**保存模型与资料，**DSH 会话**保存对话和本次使用的 Skill，建议每个案例使用对应的独立会话。

## 2. 导入模型与配套资料

1. 点击项目选择器旁的 **新建项目**，填写名称，点击 **创建并导入**。
2. 选择原始 `.step` / `.stp` 文件，并添加产品配套表、设计说明、安装或热参数资料。
3. 点击 **导入并解析装配**，等待任务结束，再查看目录和原始模型。
4. 在 **资料与导出** 中打开配套资料，检查提取文字是否完整。以后可通过 **添加资料** 继续补充。

配套资料支持 DOCX、XLSX、PDF、CSV、TXT、Markdown 和 JSON，单份不超过 **50 MB**。扫描版 PDF 应先进行 OCR。

一个工程对应一份原始 STEP，换用另一份原始模型时应新建工程。资料读取失败会保留原件并尝试恢复；显示“待恢复”时，可等待当前 DSH 会话处理，仍无法读取则上传修复或 OCR 后的副本。

## 3. 一键建模与三维检查

确认当前工程和左侧会话正确后，点击 **一键建模**。Agent 会读取资料、整理中文单机名称、建立简化方案并处理安装接触候选。默认保持原位置和朝向；缺乏依据的质量、功耗、材料等保持未知。

等待实际作业结束后，再逐个查看关键单机。一键结果是供工程师检查和修正的初稿，不能只凭 Agent 回复“完成”判断建模已合格。

| 常用操作 | 用途 |
|---|---|
| 点击目录或三维中的单机 | 进入该单机的局部对比，右侧显示详情 |
| 原始 / 对比 / 简化 | 切换显示；建议检查时使用“对比” |
| 同步视角 / 独立视角 | 控制左右视角是否联动 |
| 整星 / 相邻安装件 | 返回整体，或查看接触记录关联的组件 |
| 眼睛图标 / 聚焦所选 | 隐藏遮挡对象，或调整到目标单机 |

目录按“工程分类 → 单机”两层展示，可搜索名称或组件 ID。名称带 **（待核实）** 时，应查看名称依据；颜色只用于区分组件。接触识别不完整时，“相邻安装件”也可能不完整。

## 4. 用工程经验修正单机

### 通过 DSH 对话修改

选中目标单机，右击 **加入 DSH 会话**，或点击右侧 **带入 DSH 聊天**。输入框会加入对象引用，补充要求后发送。引用固定了目标工程和组件，后续切换选择不会改变已经发送的对象。

尽量说清楚“改成什么、保留什么、依据什么”。例如：

> 这个陀螺仪改为“圆柱主体＋矩形底座”，保持原位姿。根据源几何和资料确定尺寸及轴向，保留底座安装面。重建后检查新增重叠，不明确的尺寸先说明。

> 这个星上计算机按面壳建模，不作为实心盒体。厚度、材料和热参数单独保存；缺少的保持未知，不根据包络体积推算质量或热容。保留原安装位置和安装区域。

Agent 执行后，查看实际几何变化及任务结果，再决定是否继续调整。工程意见和修改会被记录，供后续集中改进 Skill，当前不会实时改写通用规则。

### 直接修改方案

只选中一个单机时，可在右侧选择 **盒体、圆柱＋底座、面壳、源几何**，修改组成、尺寸、热属性和安装区域，再点击 **应用并重建**。

预设只是起始模板，需要检查尺寸和轴向。坐标和长度使用单机局部坐标及毫米；未知热属性留空。**面壳输出面几何，壳厚另存，不是薄壁实体。**

表单修改在重建成功前只是草稿，切换单机前应先应用。需要保留当前结果时，在 **方案副本** 输入名称，点击 **保存当前已应用方案为副本**。以后点击 **载入** 可重建该方案；副本不包含未应用的草稿，也不回滚整个工程，载入后需复查接触。

## 5. 检查干涉与热接触

进入 **检查与问题**，点击 **检查几何与贴面**，等待任务结束。

| 检查内容 | 处理原则 |
|---|---|
| 原始真实干涉 | 核查源模型和实际安装意图 |
| 简化新增重叠 | 优先细化或拆分简化表示，保持真实组件位姿 |
| 未完成检查 | 查看超时、失败和未知项，不能当作通过 |

点击问题记录可查看相关组件。即使列表为空，也要核对源几何、简化几何的检查完整性。面壳没有实体体积，不能用零交叠体积证明没有穿透。

在 **热接触关系** 中点击组件对，进入 **安装与热接触**：选择双方安装区域，填写判断依据，将状态设为候选、工程师确认、待复核或已排除，然后 **保存接触定义**。没有合适区域时，先在单机详情中定义并重建。

几何贴近只说明可能接触；确认热连接需要有效的双方区域及工程依据。接触面积和热导通缺失时留空。热导通单位为 **W/K**，不能直接填写单位为 W/(m²·K) 的接触换热系数。修改几何后，相关接触会变为待复核，应重新检查。

## 6. 导出供后续使用的文件

在 **资料与导出** 点击 **生成导出包**，等待结束并阅读 STEP 检查状态，然后下载所需产物。

| 产物 | 内容 |
|---|---|
| 简化模型 · STEP | 当前方案的实体和/或面壳，保留当前装配位姿 |
| 单机方案与热属性 | 可重建参数、壳厚、材料等热属性及安装区域 |
| 热接触关系清单 | 组件对、双方区域、确认状态及接触参数 |
| 项目导出包 · ZIP | 上述成果及预览、属性出处、检查和反馈记录 |

向下游交付时，建议同时提供 **STEP＋单机方案与热属性＋热接触清单**。模型修改后应重新导出，保证各文件属于同一修订。

“STEP 可读取，拓扑检查通过”表示文件检查通过，仍需工程复核；显示拓扑缺陷或有效性未确认时，先处理问题。导出 ZIP 是成果包，不是包含全部原始资料和聊天记录的完整工程备份。

## 7. Skill 与常见问题

点击顶部 **Skill** 可查看规则正文、资源和版本指纹。需要试用新规则时，使用 **导入 / 另存候选** 保存版本，在 DSH **新建会话** 后选择并 **绑定当前会话**。仅切换下拉框不会更换已绑定规则，也不会自动重建模型。

| 现象 | 建议处理 |
|---|---|
| 一键建模提示先选会话 | 在左侧创建或选择 DSH 会话，并确认模型可用 |
| 服务未连接 | 核对管理员提供的服务地址和令牌，检查连接 |
| 资料已保存但读不到正文 | 查看资料详情，等待恢复或补充可读副本 |
| 模型没有变化 | 查看任务是否结束；表单修改需“应用并重建” |
| 工程忙或版本变化 | 等待当前任务结束，刷新项目后再操作 |
| 导出链接变为尚未生成 | 当前修订已变化，重新生成导出包 |

遇到无法自行解决的问题，向管理员提供工程名称、修订、操作时间和错误截图即可。外部批量测试及 API 使用另见 [业务接口文档](workbench-api.md)。
