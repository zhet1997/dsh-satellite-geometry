# 卫星热设计几何工作台：本轮需求与验收

状态：用户已确认本轮需求并授权自主开发。日期：2026-10-09。

本文件汇总本轮讨论的最终决定，作为实现、验证和后续交接的依据。它替代早期版本中多用途优先、按 STEP 原始目录展示以及自动实时升级 Skill 的设想。

## 1. 场景与目标

输入一个复杂的整星 STEP 文件及产品配套表、设计说明等辅助资料，识别单机和结构，整理安装与接触关系，生成合理的简化几何。工程师在 DSH 对话和三维工作台中检查并纠正模型，产出供后续热分析前处理使用的干净文件。

这是承载热设计工程师经验的平台工具。自动简化是起点，工程师可以要求“陀螺仪改成圆柱加矩形底座”“星上计算机用面壳表示，热容按资料填写”。Agent 应修改当前模型并刷新显示，完整记录意见和实际修改。几何表达不能替代物理参数，也不能凭包络体积推算设备质量或热容。

计算服务继续运行于可迁移的 Docker 中，客户端沿用 DSH 的模型连接。原项目保持只读；已有项目、源文件和数据卷必须保留。本版主要用途为热分析，不包含网格、求解器建模或热分析求解。

## 2. 工作台

| 项目 | 本轮要求 |
|---|---|
| 布局 | 保留原生 DSH 对话与工作台同屏；工作台左树、中间原始/简化对比、右单机详情 |
| 用途 | 顶部显示热分析模式，删除右侧长期占用大面积的用途选择 |
| 工程树 | 面向工程的最多两层树；一级分组、二级设备或结构件；内部几何在详情查看 |
| 名称 | 中文且简洁；优先匹配配套资料，其次有证据的判断；代号与原名保存在详情和搜索中；不可靠身份标为待识别 |
| 源映射 | 保留完整源 STEP 树、实例和稳定组件标识，展示层次不改变源映射 |
| 对比 | 默认并排；相机锁定默认开启，可以关闭；点选单机自动隔离并适配显示 |
| 周边 | 可返回整星，可显示当前单机相邻安装结构 |
| 配色 | 按单机稳定区分色，两侧及不同修订保持一致；选择用轮廓/强调显示 |
| 对话 | 树和几何右键可带入当前 DSH 会话；上下文包含工程、组件、方案、接触、文件读取入口 |
| 刷新 | Agent 修改后自动刷新，保留当前选区与合理相机状态 |
| 风格 | 紧凑专业软件风格，提高文字可读性，减少常驻解释小字，保留影响判断的未知/待确认提示 |

## 3. 单机建模方案

方案是可保存和可重建的结构化对象，至少包括稳定组件标识、表示类型、组成、命名参数、尺寸依据、源局部坐标及位姿、已知热属性、安装区域和接触定义。

本轮支持保留源几何、盒体、圆柱、组合体、面壳等表达；陀螺仪的圆柱加底座应能通过参数重建。面壳由面组成，不输出薄壁实体冒充面壳；厚度、材料和热参数在配套清单中单独保存，供下游生成壳单元。按表示类型验证：实体检查闭合/正体积，面壳检查有效面与面积，并验证 STEP 重读后仍为面表示。

默认保持源布局。简化新增重叠优先细化或拆分包络；仍不能消除则标为问题。真实组件只在已有真实装配问题或明确布局优化请求下考虑移动，并且要有充分安装约束，缺失约束的组件保持原位姿。

采用轻量保存机制：当前方案直接修改；提供“保存当前方案为副本”、命名及载入恢复。共用一份原始几何，记录对话与修改摘要，不建设逐步接受、撤销、多版本比较或每步完整几何历史。保存副本本身不表示工程师已认证模型正确。

## 4. 安装、检查和交付

检查页面聚焦干涉和安装/接触。区分源模型真实干涉与简化引入的重叠，计算超时和未检查不能显示为通过。

接触清单表达双方组件、各自安装区域/面、接触面积或未知值、资料或几何证据、确认状态及缺失参数。几何邻近只能生成候选，不能自动认证热导通。新方案重建后应更新关联区域映射；不能可靠映射时标为待复核。接触为空且未检查时明确显示未知。

提供当前单机接触关系图、关联行与三维高亮；显示安装对象和区域。导出页主要提供简化模型与热接触清单。交付包含 STEP、稳定标识及源映射、建模方案、面壳厚度/材料/已知热属性、热接触及其状态。保持现有可追溯 JSON 和可下载交付包能力。

## 5. 工程师经验与 Skill

工程师修改即时作用于当前模型，记录对应会话/引用、组件、意见、实际修改、方案/副本、软件版本及 Skill 指纹。记录用于以后集中整理和升级 Skill，不做实时提炼、自动训练或在线自我升级。

界面提供 Skill 正文与配套资源查看、候选版本导入/另存及明确选择。内容以不可变版本保存，实际运行记录版本和内容指纹。工程和 DSH 会话使用明确绑定，旧会话已加载的内容不能被另一运行的版本切换悄悄替换。更换后测试应使用新的会话，保留旧会话记录。

## 6. 外部测试接口

测试框架由外部实现。本插件不内置场景管理、批量调度、gate 打分或版本比较看板。

界面按钮和外部程序共用业务校验、任务与存储。提供可文档化的真实业务接口：

1. 查询 Skill 版本、内容/资源及指纹，导入候选版本，指定运行版本并读取实际绑定。
2. 创建独立工程、导入 STEP/资料、读取工程及资料内容。
3. 将工程/选区/方案绑定到指定 DSH 会话；复用 DSH 原生会话创建、prompt、history 能力。
4. 自动建模、读取和修改方案、重建几何、维护接触、保存及载入方案副本。
5. 查询和取消异步任务，区分完成、失败、取消与检查未知。
6. 读取方案、测量、干涉、接触、未知项、反馈记录及可下载交付文件。

操作使用稳定 ID；长任务有状态；修改应检查项目修订，防止覆盖并发编辑。独立工程和会话之间不得混用 Skill 或选择上下文。文件提供可读取的服务/代理入口，不能将 Docker 内路径当成本机文件地址。

## 7. 可检查的验收标准

| 场景 | 验收证据 |
|---|---|
| 文档与 Git | 先独立提交本需求；保存现有未提交改动；实现与验证有后续提交 |
| 原始整星 | 使用原项目算例或已有案例建立独立验证工程，保留旧项目；树最多两层，内部源结构仍可追溯 |
| 组合单机 | 用圆柱加矩形底座的结构化方案重建；验证尺寸、原位姿、组件 ID 和可读 STEP |
| 面壳 | 重建面壳；验证有效面、面积、零实体及导出重读保持面表示；厚度/材料独立记录 |
| 副本 | 保存、改动、载入能恢复方案参数及几何；不复制源文件；不引入额外接受流程 |
| 接触 | 小案例验证安装区域、接触候选/确认/未知状态；改动后映射复核；清单与视图关联 |
| 对比交互 | 实际浏览器验证同步视角、选单机隔离、返回整星、稳定配色和右键对话 |
| DSH 上下文 | 会话能通过真实工具读取工程、文件资料、方案和接触；旧引用不随当前选择漂移 |
| Skill 隔离 | 两个独立运行指定不同版本；记录内容指纹，互不替换；查看与导入可用 |
| 无界面流程 | 程序创建工程、指定 Skill、导入案例、修改/重建、等待、检查及下载结果，取得结构化证据；不依赖 UI 点击 |
| 回归与发布 | 后端几何/接口、MCP、插件及前端构建通过；本机启动入口可用，数据卷保留；记录未解决限制 |

## 8. 实施顺序与边界

先落实方案/副本/记录数据模型及几何重建，再完善接触与导出，然后扩展 MCP、DSH/Skill 绑定及外部接口，最后调整界面并做真实案例与浏览器验证。数据兼容采用惰性补充/迁移，旧组件原始几何和已有修订不可丢失。

自动中文命名、辅助资料语义匹配以及经验性的方案选择由 DSH 模型与 Skill 完成；确定性的几何计算由服务完成。没有资料证据的设备身份、热参数或接触确认保留未知。测试报告必须区分功能运行成功和热工程质量认证。
